# Original poster style — version 2.2

All 14 PNG assets were made or restyled with the built-in ImageGen tool using the two movie posters supplied by the owner as costume and visual references. The reference JPEGs themselves are not distributed. The image files retain their generated alpha channels and dimensions; game rendering clips animation cells using src/assets.js.

The art direction uses red-and-gold Western wood type, blue sky, orange mesas, printed grain, gold Chips costumes, and Sugar’s brown corduroy / red shirt / cream paisley tie. Menus, story pages, the shop, journal and HUD use the same palette. Rye is bundled from the official Google Fonts repository under SIL OFL 1.1; fonts/OFL.txt is included in both releases and embedded in the single-file edition.

Only the owner-authorized likenesses are used; concealed faces remain concealed. Other roles retain original designs. No film soundtrack or voices are added. The existing 46 original sounds and adaptive score remain intact.
