# Frontier artwork — version 3.0

All six atlases were generated with the built-in ImageGen tool, with transparent_background=true. This used the built-in generation/editing path, not a CLI or external API. Original generated PNGs are retained unchanged. Runtime frame rectangles isolate neighboring cells. Preview them in `tests/frontier-browser.html`.

The Foot has a new concealed face, indigo coat, burgundy hat, mechanical boot and peg leg. No guest performer reference was supplied for this character. Sugar and Chips use only the owner-authorized Shaggy/J appearance references. Poot and the axe raider have covered faces. The existing owner-supplied studio logo is unchanged.
